# Frontend — Mini ERP + CRM Operations Portal

React + TypeScript + Vite + Tailwind CSS SPA. See the [root README](../README.md) for the full
setup, deployment, and architecture write-up — this file just covers the frontend-only quick
commands.

```bash
cp .env.example .env             # defaults to http://localhost:4000/api
npm install
npm run dev                      # http://localhost:5173
```

| Command | What it does |
|---|---|
| `npm run dev` | Start the Vite dev server with hot-reload |
| `npm run build` | Type-check and produce a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | ESLint |
